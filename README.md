# faro

**faro** es el design system de **faro salud**: el conjunto de fundamentos visuales, componentes y pautas con los que se construyen todas las pantallas de la app.

> **Estado:** fase inicial. El repositorio acaba de crearse y todavía no contiene código ni componentes. Este README recoge la visión y el alcance previstos.

---

## Qué es faro salud

faro salud es una app de salud personal. Cada persona entra en su portal y tiene en un solo sitio todo lo relacionado con su salud:

- **Recetas y medicación**: qué recetas tiene activas y qué medicación tiene que tomar, y cuándo.
- **Análisis y chequeos**: los análisis y revisiones que se ha hecho a lo largo del año.
- **Citas**: sus próximas citas médicas (por ejemplo, con el dentista).
- **Consultas grabadas y notas**: puede grabar sus consultas y tomar notas para no perder lo que le dijeron.
- **Agente de IA**: puede hablar con un agente de IA sobre cómo se siente.
- **Objetivos anuales de revisiones**: puede marcarse objetivos de revisiones al año (vista, dientes, medicina general).
- **Panel de datos y métricas**: un panel para seguir todo lo anterior de un vistazo.

## Qué es faro

faro es el design system que da forma a esa experiencia. Su objetivo es que todas las partes de faro salud se vean, se comporten y se entiendan igual, y que construir pantallas nuevas sea rápido y coherente.

Al tratarse de una app de salud, faro prioriza:

- **Claridad**: la información médica (dosis, fechas, resultados) tiene que leerse sin ambigüedad.
- **Accesibilidad**: contraste, tamaños de texto, navegación por teclado y lectores de pantalla, pensando en personas de cualquier edad y capacidad.
- **Calma y confianza**: un lenguaje visual sereno, sin ruido, adecuado para hablar de temas sensibles.
- **Coherencia**: los mismos patrones para los mismos problemas en toda la app.

## Para quién es

- **Equipo de diseño** de faro salud: una base común de estilos, componentes y patrones para diseñar pantallas.
- **Equipo de desarrollo**: componentes listos para usar que implementan esos diseños de forma consistente.
- **Producto y contenido**: pautas de tono, redacción y uso para que la experiencia sea coherente.

Y, en última instancia, para **las personas que usan faro salud**, que se benefician de una app clara, accesible y predecible.

## Qué vamos a construir

### Fundamentos (tokens)
- Color (incluidos estados: éxito, aviso, error, información) con modo claro y oscuro.
- Tipografía, espaciado, retícula, radios, sombras y elevación.
- Iconografía.
- Movimiento y transiciones.

### Componentes base
- Botones, enlaces, campos de formulario, selectores, casillas, interruptores.
- Tarjetas, listas, pestañas, modales, avisos y notificaciones.
- Navegación del portal.

### Componentes de dominio de salud
- **Medicación**: tarjeta de medicamento, pauta y recordatorio de toma.
- **Recetas**: estado y vigencia de cada receta.
- **Análisis y chequeos**: resultados con valores y rangos de referencia, historial anual.
- **Citas**: calendario, tarjeta de cita y recordatorios.
- **Consultas y notas**: grabador de consulta, reproductor y editor de notas.
- **Conversación con el agente de IA**: interfaz de chat, mensajes y estados.
- **Objetivos de revisiones**: progreso por tipo (vista, dientes, medicina general).
- **Panel de métricas**: indicadores, gráficas y resúmenes de progreso.

### Pautas
- Accesibilidad.
- Tono y redacción para contenido de salud.
- Patrones de uso y buenas prácticas para cada componente.
